👓 Sensor de Presença

Tecnologia responsável pela deteção automática da utilização dos óculos de proteção.

🎯 Função Principal

O sensor de presença é responsável por confirmar automaticamente se os óculos de proteção estão corretamente colocados no operador.

Esta validação garante que a máquina apenas funciona quando existe proteção ocular adequada.

✨ Características

  • ✔️ Deteção instantânea.
  • ✔️ Elevada precisão.
  • ✔️ Compatível com sensores capacitivos.
  • ✔️ Integração direta com o sistema.
  • ✔️ Operação contínua em ambiente industrial.

⚙️ Funcionamento

Quando os óculos são colocados corretamente, o sensor gera um sinal digital que é enviado para o microcontrolador.

Caso sejam removidos, a comunicação é interrompida e a máquina é imediatamente bloqueada.
